# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shopping application.

## Project Description

This application allows users to browse different houseplants,
view plant information and prices, and add plants to a shopping cart.

## Features

- Browse houseplants by category
- View plant images
- View plant names and prices
- Add plants to cart
- Increase and decrease quantities
- Remove plants from cart
- View total cart amount
- Continue shopping
- Checkout option

## Technologies

- React
- Redux Toolkit
- React Router
- JavaScript
- CSS
